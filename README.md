# Bilibili 观看记录增强（Chromium 扩展）

一个基于 Manifest V3 的 Chromium 内核浏览器扩展，用于在本地保存 B 站视频的观看记录，
提供独立查询页、搜索、封面显示、导出 JSON 与导入（历史记录页 HTML / 导出 JSON）。

## 功能

- **自动记录**：打开 B 站视频页（`/video/BV...`）并观看超过 5 秒后自动记录。
- **API 优先**：优先调用 B 站官方 API（`x/web-interface/view`）获取标题与 UP 主；
  API 不可用时自动回退到页面 DOM 数据，保证任何情况下都能记录。
- **不重复记录**：同一视频（同一链接）只保留一条记录；再次观看时仅更新「最后观看时间」。
- **字段精简**：每条记录只保存 4 个字段——标题、源链接、发布者（UP 主）、最后观看时间（精确到小时）。
- **独立查询页**：点击扩展图标直接打开查询页（`chrome-extension://<扩展ID>/history.html`，
  已打开时自动聚焦）。
- **搜索**：按视频标题或 UP 主模糊搜索（不区分大小写）。
- **按日期查找**：查询页提供日历样式的日期选择（开始/结束日期），按最后观看日期筛选记录。
- **封面显示（API 获取 + 懒加载）**：视频封面通过 B 站 `view` API 的 `pic` 字段获取
  （同步/导入时直接用接口或页面返回的封面预填缓存），仅当封面元素**进入视口**（提前 300px）
  才触发批量请求加载，屏幕外的项目不会加载封面；封面缓存于本地（不写入记录，
  记录仍只有标题/链接/UP主/时间 4 个字段）。
- **列表 / 网格视图**：查询页头部可一键切换列表（缩略图行）与网格（封面卡片）展示，
  选择持久化到设置。
- **导入**（设置页）：可导入**历史记录页 HTML 文件**（浏览器保存的
  `https://www.bilibili.com/history` 页面，支持卡片结构与内嵌 JSON 两种解析）
  或**本扩展导出的 JSON 文件**，导入后自动合并去重。
- **导出 JSON**：设置页「导入」卡片中的「导出 JSON」按钮，一键导出全部记录
  （含导出时间、数量等元信息）。
- **清空记录**：设置页「导入」卡片中的「清空记录」按钮，需在确认弹窗中输入 **YES**
  并点击「确定」才会清除（弹窗文字居中：确定要清空全部记录吗 / bilibili中的历史记录
  **不会同步清除** / 如果确定要清空全部记录，请在下方输入 **YES**）。
- **同步 B 站官方记录**：登录状态下可从官方观看历史 API（`x/web-interface/history/cursor`
  及 `x/v2/history`）拉取记录并合并去重（自动尝试 WBI 签名 `w_rid` 与无签名等方式）。
- **自动同步**：设置页启用后，扩展按自定义间隔（1~10080 分钟）在后台定时从 API 拉取历史；
  刚启用时立即同步一次。
- **设置页**：自定义颜色主题、背景图片（无大小限制，小于 20MiB 的本地图片存入应用数据、
  更换或清除时自动删除旧图）、默认显示模式、导入、日志（多等级：调试/警告/错误，
  支持筛选、复制、清空与登录态检查）。

## 安装

1. 打开 Chromium 内核浏览器的扩展管理页（`chrome://extensions` 或 `edge://extensions`）。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `bilibili-watch-history`。
4. 访问任意 B 站视频页观看，再打开查询页查看记录。

> 注意：同步官方记录（含自动同步）需要已登录 B 站账号（使用浏览器中的登录态 Cookie）。

## 使用说明

| 入口 | 能力 |
| --- | --- |
| 扩展图标（点击） | 直接打开/聚焦查询页 |
| B 站视频页 | 自动记录观看行为 |
| 查询页 `history.html` | 搜索、按日期筛选、同步、删除单条、列表/网格切换 |
| 设置页 `settings.html` | 颜色主题、背景图片、显示模式、自动同步、导入、导出 JSON、清空记录（需输入 YES 确认）、日志 |

设置页卡片顺序（从上到下）：颜色主题 → 背景图片 → 显示 → 自动同步 → 导入 → 日志。

### 导入说明

- **历史记录页 HTML**：在浏览器中打开 `https://www.bilibili.com/history`，右键 →「另存为」
  保存整个网页（**未完全加载、未出现「已经到底啦~」结束标记的文件也可导入**，能解析
  多少就导入多少），然后在设置页「导入」中选择该 HTML 文件；扩展自动解析历史卡片并合并去重。
- **导出 JSON**：在查询页或弹窗点击「导出 JSON」得到的文件，可在设置页「导入」中
  重新导入（例如换浏览器后恢复记录）。

### 背景图片说明

- 支持图片链接或本地图片，**无大小限制**。
- 小于 20MiB 的本地图片会存入扩展应用数据（`chrome.storage.local`）；
  **更换或清除背景时自动删除旧图**，避免数据堆积。
- 大于等于 20MiB 的图片直接使用（不存入应用数据），保存后仍随设置持久化。

## 数据说明

- 存储位置：`chrome.storage.local`（仅存于本机，不上传任何数据）。
- 存储键：`bwh_records_v1`（记录）、`bwh_settings_v1`（设置）、`bwh_bg_image_data`
  （小于 20MiB 的已存背景图，更换/清除时删除）；封面缓存存于 `chrome.storage.session`
  （`bwh_cover_cache_v1`，浏览器会话内有效，上限 300 条）。
- 记录结构：

```json
{
  "title": "视频标题",
  "url": "https://www.bilibili.com/video/BV1xx411c7mD",
  "up": "UP主名称",
  "lastWatchedAt": 1700000000000
}
```

- `lastWatchedAt` 为毫秒时间戳，写入时截断到整小时（如 `2025-01-01 12:00`）。
- 去重键为规范化后的链接（去掉 `?`/`#` 及尾部斜杠），同一视频的多 P（分P/合集）只记一条。

## 导出格式

```json
{
  "app": "bilibili-watch-history",
  "version": "1.2.0",
  "exportedAt": "2025-01-01T04:00:00.000Z",
  "count": 2,
  "records": [
    { "title": "…", "url": "https://www.bilibili.com/video/BV…", "up": "…", "lastWatchedAt": 1735704000000 }
  ]
}
```

├── manifest.json            # MV3 清单（权限：storage, alarms, unlimitedStorage；点击图标直接打开查询页）

## 隐私与限制

- 所有记录与设置保存在浏览器本地，扩展不向任何第三方发送数据；仅在你主动点击「同步」或
  启用自动同步时调用 B 站官方 API。
- 若 B 站 API 因接口调整（如 wbi 签名变更）而不可用，自动回退 DOM 提取，记录功能不受影响。
- 观看不足 5 秒、非 `/video/` 页面（如番剧、直播）不会记录。
- 导入的 HTML 文件仅在本机解析，不会上传。
