# Bilibili 观看记录增强

一个基于 Manifest V3 的 Chromium 内核浏览器扩展，用于在本地保存 B 站视频的观看记录，
提供独立查询页、搜索、封面显示、导出 JSON 与导入（历史记录页 HTML / 导出 JSON）。

## 功能

- **搜索**：按视频标题或 UP 主模糊搜索（不区分大小写）。  
- **按日期查找**：查询页提供日历样式的日期选择（开始/结束日期），按最后观看日期筛选记录。  
- **导出 JSON**：设置页「导入」卡片中的「导出 JSON」按钮，一键导出全部记录。  
- **自动同步**：从设置页启用后，扩展按自定义间隔在后台定时从 API 拉取历史记录。  
- **设置页**：自定义颜色主题、背景图片。  

## 安装

在[Releases](https://github.com/CMR0649/bilibili-history/releases)页面下载crx文件  
打开浏览器的扩展程序页面，并打开开发者模式  
将crx文件拖入即可安装  

### 导入说明

- **历史记录页 HTML**：在浏览器中打开 `https://www.bilibili.com/history`，右键 →「另存为」
  保存整个网页，然后在设置页「导入」中选择该 HTML 文件。
> [!TIP]
> 建议滚动到页面最下方以导入全部历史记录  
  
- **导出 JSON**：在查询页或弹窗点击「导出 JSON」得到的文件，可在设置页「导入」中
  重新导入（例如换浏览器后恢复记录）。
